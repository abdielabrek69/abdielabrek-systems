## Características del portafolio

El sitio fue desarrollado buscando combinar presentación profesional con una experiencia visual interactiva.

### Experiencia 3D

El encabezado utiliza una escena generada mediante **Three.js/WebGL**, incluyendo partículas 3D animadas e interacción con el movimiento del cursor.

### Animaciones

El sitio incorpora:

* Animaciones de entrada.
* Aparición progresiva de secciones.
* Efectos hover.
* Animaciones de tarjetas.
* Timeline de experiencia.
* Efectos de iluminación.
* Movimiento e interacción de partículas.
* Animaciones adaptadas a dispositivos móviles.

### Responsive Design

El diseño está preparado para:

* Computadoras.
* Laptops.
* Tablets.
* Teléfonos móviles.

### Accesibilidad

Se incluyen consideraciones como:

* Navegación mediante teclado.
* Enlace para saltar al contenido.
* Etiquetas semánticas.
* Soporte para `prefers-reduced-motion`.
* Contraste visual.
* Diseño adaptable.

## Ejecutar el proyecto localmente

Clona el repositorio:

```bash
git clone https://github.com/abdielabrek69/abrek-systems.git
```

Entra al directorio:

```bash
cd abrek-systems
```

Puedes abrir `index.html` directamente en el navegador.

Para una mejor experiencia de desarrollo, se recomienda utilizar **Visual Studio Code** junto con **Live Server**.

También puedes utilizar cualquier servidor HTTP local.
