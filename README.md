# Abdiel Abrek — Portfolio 3D

Portafolio profesional experimental para Abdiel Abrek, Ingeniero en Sistemas y TI.

## Incluye
- Hero interactivo con Three.js y 24,000 partículas.
- Respuesta de partículas al movimiento del mouse.
- Anillo 3D animado y estética tecnológica.
- Animaciones de aparición al hacer scroll.
- Navegación activa y menú responsive.
- Typing effect para áreas técnicas.
- Timeline profesional.
- Skills, formación, proyectos y contacto.
- Soporte para `prefers-reduced-motion`.
- Sin framework de frontend; HTML/CSS/JS + Three.js por CDN.

## Ejecutar
Abre `index.html` en un navegador moderno. Para máxima compatibilidad con módulos ES y CDN, se recomienda servir la carpeta con un servidor local, por ejemplo VS Code Live Server.
