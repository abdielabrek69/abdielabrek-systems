## Publicar en GitHub Pages
1. Sube el contenido de esta carpeta al repositorio `abrek-systems`.
2. En GitHub entra a **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama que contiene estos archivos (por ejemplo `main`) y la carpeta `/ (root)`.
5. Guarda y espera la publicación.
6. La URL prevista es: `https://abdielabrek69.github.io/abrek-systems/`

No requiere PHP, MySQL ni servidor para funcionar en GitHub Pages.
